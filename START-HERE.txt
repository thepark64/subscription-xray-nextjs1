SUBSCRIPTION X-RAY - SETUP (in order)

1. Install Node.js 20+ from nodejs.org (once). Open this folder in VS Code and run:
      npm install

2. SUPABASE (supabase.com -> your project)
   a. SQL Editor -> paste ALL of supabase/schema.sql -> Run.
      (Safe to re-run. It also fixes an older database: removes the old
      grant_scan_credit function and the risky profile-insert policy.)
   b. Project Settings -> API: copy the URL, anon key and service_role key.
   c. Authentication -> URL Configuration:
        Site URL:       https://subscription-x-ray.vercel.app
        Redirect URLs:  https://subscription-x-ray.vercel.app/**
                        http://localhost:3000/**
      (Without this, password-reset and confirm-email links will not work.)
   d. Authentication -> Providers -> Email: set minimum password length to 8.

3. RAZORPAY (dashboard.razorpay.com) - use TEST mode first
   a. Account & Settings -> API Keys -> generate. Copy Key Id and Key Secret.
   b. Webhooks -> Add webhook:
        URL:    https://subscription-x-ray.vercel.app/api/razorpay/webhook
        Secret: any long random string (you invent it; reuse it below)
        Event:  payment.captured   (only this one is needed)

4. Copy ".env.example" to ".env.local" and fill in all 6 values.
   Run:  npm run dev     -> http://localhost:3000
   (Payments cannot complete locally because the webhook needs a public URL -
   test payments on the deployed site.)

5. Deploy: push to GitHub -> vercel.com -> New Project -> pick the repo.
   Add the same 6 values under Environment Variables, then redeploy.

6. TEST END-TO-END in Razorpay test mode: sign up -> confirm email -> scanner ->
   Pay -> use Razorpay's test card -> credits should appear within seconds.
   Then switch to LIVE keys (and a LIVE webhook) and update the 3 Razorpay vars.

Commands:  npm run dev | build | lint | typecheck | test

Before launch: read the draft wording on /terms, /privacy and /refund and get it
reviewed - they are templates, not legal advice. Razorpay needs them public.
